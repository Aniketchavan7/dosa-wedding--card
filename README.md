# dosa-wedding--card

Wedding invitation card website for Doshiba & Suhel.

## Features
- Interactive cinematic wedding card
- Haldi, Nikah, and Reception event details
- Duas & printable Nikah Mubarak gift card PDF
- Responsive on mobile and desktop
- Video and audio experience

## Deployment

### Netlify (Automatic with GitHub)
1. Go to [app.netlify.com](https://app.netlify.com/)
2. Click **Add new site** > **Import an existing project**
3. Choose **GitHub** and select `Aniketchavan7/dosa-wedding--card`
4. The build settings are configured automatically via `netlify.toml` (Publish directory: `.`)
5. Click **Deploy dosa-wedding--card**

### Netlify Drop (Instant Manual Drag-and-Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop this folder
3. Instant live link is generated!
